## 四、关键 SDK 事实（避免重复踩坑）

- `Area` 为全局 ambient 类型，误从 `@kit.ArkUI` import 会报 `no exported member`。
- `LengthMetrics` 在 kit 作用域内仅为类型，**必须 `import { LengthMetrics } from '@ohos.arkui.node'`** 才能当值用（`.fp()/.px()/.vp()`）。
- `Text` 构造仅接受 `string|Resource`；`setStyledString` 是 **`TextController` 方法**，须 `Text('',{controller})` + `controller.setStyledString(...)`。
- `TextStyle.fontSize` 类型为 `LengthMetrics`（非 number），须 `LengthMetrics.fp(n)`。
- `uiMaterial` 从 `@ohos.arkui.uiMaterial` 默认导入；`systemMaterial` 是 `CommonMethod`。
- `StartupTask.init` 真实形参为 `AbilityStageContext`，但该类型不在 `@kit.AbilityKit` 导出，用 `Context` 即可（方法双变通过）。
